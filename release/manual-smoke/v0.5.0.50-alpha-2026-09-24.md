## Confirmed smoke scenarios

The maintainer manually confirmed the following on the exact source commit above:

- application starts successfully from the local Release publish;
- About UI reports `0.5.0.50-alpha`;
- notification-area icon is present;
- automatic mode applies saved profiles correctly in two tested applications;
- `Ctrl+Alt+I` toggles temporary correction for the active window;
- `Ctrl+Alt+Shift+I` adds/toggles the active application assignment and the result is visible/removable in configuration;
- `Emergency disable all overlays` removes active overlays and disables automatic mode;
- automatic mode can be enabled again after emergency disable;
- editing and saving a custom profile persists the changed value and affects the assigned application.
