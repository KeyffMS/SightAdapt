# SightAdapt™ 0.5.0.50-alpha

SightAdapt is a free, open-source Windows application for per-application visual accessibility and color correction.

- **Status:** Alpha / prerelease
- **Platform:** Windows 10 version 2004 or later, or Windows 11
- **Architecture:** x64
- **Package:** self-contained portable ZIP
- **Website:** https://aiteracja.pl/sightadapt/
- **Source:** https://github.com/KeyffMS/SightAdapt
- **Documentation:** https://github.com/KeyffMS/SightAdapt/tree/main/docs
- **Privacy:** https://github.com/KeyffMS/SightAdapt/blob/main/PRIVACY.md
- **License:** MIT License

## Highlights

This release publishes the current 0.5.0.50 alpha implementation with per-application visual profiles, automatic assignments, configurable overlay scope, native Win32 popup-menu handling, profile editing and explicit emergency overlay shutdown.

## Upgrade and migration

Settings are schema-versioned and migrated by the application when supported. Keep a backup of `%LOCALAPPDATA%\SightAdapt\settings.json` before relying on an alpha upgrade. A newer unsupported schema is not silently overwritten.

## Known limitations

- only one foreground application session is corrected at a time;
- native menu-specific handling is limited to Win32 `#32768` popup menus;
- protected or DRM-controlled content may remain unavailable or unfilterable;
- elevated applications may require a compatible integrity level;
- remote desktop sessions and some graphics drivers may behave differently;
- broad compatibility and endurance testing are not complete.
