System requirements

  • Windows 10 version 2004 or later, or Windows 11;
  • x64 processor;
  • user permission to start a desktop application;
  • compatible desktop composition and graphics driver.

Install and start

  1. Download only from a project-controlled Aiteracja page, the official GitHub repository or an approved package listing.
  2. Verify the checksum when practical.
  3. Extract the archive to a user-controlled directory.
  4. Start SightAdapt.exe.
  5. Use the notification-area icon to open configuration.

Verify the checksum in PowerShell

Get-FileHash .\SightAdapt-0.5.0.50-alpha-win-x64.zip -Algorithm SHA256

The resulting hash must match {{SHA256}}.

Windows reputation warning

Unsigned or newly published open-source binaries may trigger Microsoft Defender SmartScreen. Do not disable system protection. Verify the project-controlled source, the published hash and the GitHub Release before deciding whether to run a file.

Removal

Exit SightAdapt, remove the extracted application files and, if you also want to remove saved configuration, delete %LOCALAPPDATA%\SightAdapt\settings.json. Deleting that settings file removes saved profiles and assignments.

Alpha warning. Keep the emergency-disable command available and test the application with non-critical work before relying on it for extended sessions.
