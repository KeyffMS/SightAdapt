System requirements

  • Windows 10 version 2004 or later, or Windows 11.
  • x64 processor.
  • User permission to start a desktop application.
  • Compatible desktop composition and graphics driver.

Install and start

  1. Download only from a project-controlled URL or approved package listing.
  2. Verify the checksum when practical.
  3. Extract the archive to a user-controlled directory.
  4. Start SightAdapt.exe.
  5. Use the notification-area icon to open configuration.

Verify the archive

Run the following in PowerShell from the directory containing the downloaded ZIP:

Get-FileHash .\SightAdapt-0.5.0.50-alpha-win-x64.zip -Algorithm SHA256

The resulting hash must equal:

c6dc5ba5c0356c84b32a74d298015d63158c57886b835e411da0b60f306fd711

Windows reputation warning

Unsigned or newly published open-source binaries may trigger Microsoft Defender SmartScreen. Do not disable system protection to run SightAdapt. Verify the source URL, release page and checksum before deciding whether to run a downloaded file.

Removal

Exit SightAdapt, then remove the extracted application files. To remove saved profiles and assignments as well, delete %LOCALAPPDATA%\SightAdapt\settings.json. Deleting that file permanently removes the local SightAdapt configuration.

Alpha use

This is an alpha release. Keep the emergency-disable command available and test the application with non-critical work before relying on it for extended sessions.
