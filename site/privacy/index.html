Privacy

Local settings and explicit support sharing.

The current SightAdapt alpha stores configuration locally and does not transmit captured screen content or behavioral telemetry.

Data processed locally

To identify the active application and render the configured overlay, SightAdapt may read window handles, process and GUI thread identifiers, display names, executable names and paths, file-description metadata, window geometry and foreground state.

Saved settings can include assignments, enabled states, selected profiles, menu-profile references, overlay scopes and user-defined tuning values.

Local storage

Settings are stored at %LOCALAPPDATA%\SightAdapt\settings.json. The file is human-readable JSON and can contain executable paths. Those paths may contain a Windows account, organization or project name.

To reset local configuration, exit SightAdapt and remove the file. Starting SightAdapt again recreates defaults.

Screen content and network behavior

The current application does not intentionally save screenshots, record the screen, build a screen-content history, perform image recognition or transmit captured screen content.

It contains no telemetry, product analytics, advertising, remote crash reporting, automatic diagnostic upload, cloud synchronization or automatic update check.

Support information

Information reaches the project owner only when a person voluntarily sends it through GitHub or another support route. Before sharing logs, settings, screenshots or paths, remove usernames, organization names, private directory names, tokens and unrelated content.

Controller and contact for submitted support data

KeyffMS / aiteracja.pl. The current public contact route is the GitHub repository owner. For non-public material, request a private communication route before sending it.

Privately submitted support material is limited to people needed to investigate the report and is normally deleted no later than 90 days after the related support matter closes, except when a longer period is needed for an active security investigation, legal obligation, dispute or agreed follow-up.
