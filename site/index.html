Free and open source · Windows 10 and 11 · Alpha

Adapt the application in front of you.

SightAdapt™ applies configurable color correction to individual Windows application windows. Keep the rest of the desktop unchanged, assign profiles per application and stop every overlay immediately when needed.

Change one application, not your entire desktop.

System-wide display filters can affect every monitor, application and notification. SightAdapt targets the active application through a separate overlay, allowing different applications to use different visual profiles while unrelated windows remain unchanged.

Profiles per application

Assign a saved color profile to an application and let SightAdapt activate it when that application becomes active.

Separate native-menu correction

Use the application profile for native popup menus or assign a different menu profile when menu contrast needs separate treatment.

Flexible overlay scope

Choose the client area, full window, current screen or all screens according to the application and display setup.

Editable visual profiles

Adjust output black and white levels, brightness, contrast, saturation and hue, then preview the result before assigning it.

Manual and automatic controls

Toggle the active window temporarily or save an automatic application assignment.

Immediate shutdown

Remove active overlays from the notification-area menu through the emergency-disable command.

Three steps to a per-application profile.

  1. Select or activate an application.
  2. Choose or create a visual profile.
  3. Enable the assignment or use the temporary shortcut.

Built-in starting points, editable when appropriate.

None

Leave the application unchanged.

Exact invert

Apply a fixed full inversion.

Soft invert

Use an editable lower-intensity starting profile.

Custom profiles

Duplicate and adjust a profile for a particular application or display.

Individual preferences: Visual preferences are individual. SightAdapt does not choose a medically appropriate profile and does not replace professional advice.

Local settings. No screen-content upload.

SightAdapt stores its configuration locally. The current alpha does not transmit captured screen content, does not inject code into target applications and does not install a kernel driver. Application assignments may include executable paths and file metadata stored in the local settings file.

Current alpha limitations

  • Only one foreground application session is corrected at a time.
  • Native menu-specific handling applies only to Win32 #32768 popup menus.
  • Protected or digital-rights-management (DRM) controlled content may not be capturable.
  • Elevated applications may require a compatible integrity level.
  • Remote desktop and some graphics drivers may behave differently.
  • Broad compatibility and endurance testing are incomplete.
