SightAdapt™ security

Security boundaries and reporting.

Current application boundaries

  • no code injection into other processes;
  • no driver installation;
  • no saved or transmitted captured screen content;
  • runs with the current user's privileges;
  • provides an emergency tray command to remove active overlays.

Elevated applications

A target running at a higher integrity level may require a compatible integrity level before SightAdapt can interact with the relevant windows as expected.

Alpha review status

The current alpha has not completed a formal security review and must not be treated as production-ready assistive software.

Report a vulnerability privately

Do not disclose security-sensitive issues in a public GitHub issue. Until a dedicated private reporting channel is configured, contact the repository owner through GitHub and request a private communication channel.

Do not publish credentials, private screenshots, unredacted paths, confidential settings or exploit details that would increase risk.
