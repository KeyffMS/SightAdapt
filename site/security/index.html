Security

SightAdapt™ security and reporting.

The current alpha has explicit process and display boundaries and has not completed a formal security review.

Current application boundaries

  • No DLL or code injection into target applications.
  • No kernel driver installation.
  • No saved or transmitted captured screen content.
  • Runs with the current user's privileges.
  • Uses a separate input-transparent overlay.

Elevated applications

Windows integrity boundaries can affect access to elevated target applications. A target may require SightAdapt to run at a compatible integrity level. Do not weaken operating-system security settings to force compatibility.

Emergency shutdown

The notification-area menu provides Emergency disable all overlays. It removes active overlays immediately and disables automatic mode before settings persistence is attempted.

Alpha review status

The current alpha has not completed a formal security review and must not be treated as production-ready assistive software. Compatibility and endurance testing remain incomplete.

Report a vulnerability privately

Do not disclose security-sensitive issues in a public GitHub issue. Until a dedicated private reporting channel is configured, contact the repository owner through GitHub and request a private communication channel.

Do not post passwords, tokens, private keys, confidential screenshots, unredacted executable paths or sensitive customer information.
