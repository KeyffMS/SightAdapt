Bug-report checklist

  • SightAdapt version.
  • Windows version.
  • Monitor arrangement and display scaling.
  • Target application and framework when known.
  • Target privilege level.
  • Exact reproduction steps.
  • Whether emergency disable remained available.
  • Sanitized logs or paths when relevant.

Privacy: Do not attach screenshots containing private information or publish unredacted paths, usernames, organization names or confidential application content.
