Documentation

Set up SightAdapt and understand each control.

This hub covers day-to-day use. Developer and architecture documents remain maintained in the GitHub repository.

Getting started

  1. Download and extract the current release.
  2. Start SightAdapt.exe.
  3. Open configuration from the notification-area icon.
  4. Choose an application and profile, or use a temporary shortcut.

Applications

Add an application by activating it and using the persistent-assignment shortcut or configuration UI. Assignments can be enabled, disabled and removed. Executable identity and path information is stored locally for matching.

Automatic mode applies enabled assignments when their application is foreground.

Profiles

None leaves the application unchanged. Exact invert is fixed. Soft invert is editable. User-defined profiles can be created, duplicated, renamed, edited and deleted.

Preview behavior is intended to help tune a profile but does not guarantee how every application or display driver will render it.

Menus and scopes

Native Win32 #32768 popup menus can inherit the application profile or use a separate profile. Overlay scope can target client area, full window, current screen or all screens.

WPF, WinUI, Electron, Qt and other custom-rendered menus are not separately detected.

Keyboard and emergency controls

Ctrl+Alt+I toggles correction for the active supported window without changing saved settings.

Ctrl+Alt+Shift+I adds, disables or re-enables the active application's persistent assignment.

Emergency disable all overlays removes active overlays immediately and disables automatic mode.

Troubleshooting

  • For elevated target applications, use a compatible integrity level.
  • If the tray icon is missing, verify only one SightAdapt instance is running.
  • If an overlay does not appear, verify the assignment, automatic mode and target visibility.
  • If menu correction does not apply, check whether the menu is a native Win32 popup.
  • Mixed monitors, scaling, remote desktop and graphics drivers may change behavior.
  • For settings recovery, exit SightAdapt and back up or remove settings.json.
  • Protected content may remain unavailable or unfilterable.
