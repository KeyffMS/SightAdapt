SightAdapt™ documentation

Set up SightAdapt and understand each control.

Getting started

  1. Download and extract the current release.
  2. Start SightAdapt.exe.
  3. Open configuration from the notification-area icon.
  4. Assign a profile to an application or use temporary correction.

Applications

Add an application, enable or disable the assignment, choose its profile and configure automatic mode. Saved assignments use executable identity and local path data.

Profiles

Choose a built-in profile, duplicate one into a custom profile, edit output levels, brightness, contrast, saturation and hue, then rename or delete user-created profiles when no longer needed.

Menus and scopes

Native Win32 popup menus can inherit or override the application profile. Overlay scope can target the client area, full window, current screen or all screens. WPF, WinUI, Electron, Qt and custom-rendered menus may not appear as native #32768 menus.

Keyboard and emergency controls

  • Ctrl+Alt+I — temporary active-window correction.
  • Ctrl+Alt+Shift+I — toggle the active application assignment.
  • Emergency disable all overlays — remove overlays and disable automatic mode.

If another program already owns a shortcut, registration may fail.

Troubleshooting

  • For elevated targets, use a compatible integrity level.
  • If the tray icon is missing, check whether SightAdapt is still running.
  • If no overlay appears, confirm assignment state, automatic mode and scope.
  • Test mixed scaling, remote desktop and unusual graphics drivers separately.
  • For damaged settings, exit SightAdapt and back up or remove %LOCALAPPDATA%\SightAdapt\settings.json.
  • Protected content may remain unavailable or unfilterable.
