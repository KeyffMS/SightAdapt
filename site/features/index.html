SightAdapt™ features

Features designed around individual applications.

Application assignments

Saved executable-based assignments can be enabled or disabled and are resolved automatically when the matching application becomes foreground.

Visual profile management

Use built-in profiles or duplicate a profile into a user-defined copy that can be renamed, edited and deleted. Built-in profiles remain protected.

Available controls

Profiles expose output black, output white, brightness, contrast, saturation and hue. They are display adjustments, not color-calibration measurements.

Native popup menus

Supported native Win32 #32768 popup menus can inherit the application profile or use a separate profile. Custom-rendered menus are not detected as native popup menus.

Overlay scopes

Choose client area, full window, current screen or all screens. Wider scopes may affect content beyond the application window while the session is active.

Shortcuts and tray controls

Ctrl+Alt+I toggles temporary correction for the active window. Ctrl+Alt+Shift+I toggles the active application assignment. The tray menu includes an emergency command that removes active overlays.

Multi-monitor and DPI behavior

SightAdapt is designed for per-monitor-aware Windows behavior. Remote sessions, unusual graphics drivers and mixed scaling can require application-specific testing.

Settings and migration

Configuration is stored locally in schema-versioned JSON. Supported older settings are migrated; writes are designed to avoid leaving a partially written settings file.

What SightAdapt does not do

  • does not modify another application's files;
  • does not inject code into another process;
  • does not install a driver;
  • does not upload screen content;
  • does not bypass DRM or access controls;
  • does not guarantee compatibility with every rendering framework;
  • does not provide medical diagnosis or treatment.
