Features

Features designed around individual applications.

SightAdapt keeps profile selection, overlay scope and automatic activation attached to the application you choose.

Application assignments

Persistent assignments are matched primarily by executable path. Each assignment stores its enabled state, application profile, optional native-menu profile and overlay scope. With automatic mode enabled, the saved assignment activates when its application becomes the supported foreground window.

Visual profile management

Built-in profiles provide fixed or editable starting points. User-defined profiles can be created, duplicated, renamed, edited, assigned and deleted. Deleting a user profile reassigns affected applications to the built-in Soft invert profile.

Available controls

Editable profiles expose output black, output white, brightness, contrast, saturation and hue shift. These are display-personalization controls; they are not a color-calibration or clinical measurement system.

Native popup menus

Supported native Win32 #32768 popup menus can inherit the application profile or use a separate profile. WPF, WinUI, Chromium/Electron, Qt and other custom-rendered menus are outside this separate-menu boundary.

Overlay scopes

Client area excludes the title bar and frame. Full window covers the visible window. Current screen covers the target monitor. All screens covers the Windows virtual desktop.

Shortcuts and notification-area controls

Ctrl+Alt+I toggles local correction without changing saved settings. Ctrl+Alt+Shift+I adds, disables or re-enables the persistent assignment for the active application. The tray menu also exposes automatic mode and emergency shutdown.

Multi-monitor and DPI behavior

The overlay geometry follows Windows window and monitor coordinates and the application is per-monitor DPI aware. Unusual display drivers, mixed display arrangements and remote sessions may still require testing.

Settings and migration

Configuration is stored locally as schema-versioned JSON at %LOCALAPPDATA%\SightAdapt\settings.json. Supported older settings are normalized and migrated; writes are committed atomically so a failed save does not replace the last committed configuration.

What SightAdapt does not do

  • It does not modify another application's files.
  • It does not inject code into another process.
  • It does not install a driver.
  • It does not upload screen content.
  • It does not bypass DRM or other access controls.
  • It does not guarantee compatibility with every rendering framework.
  • It does not provide medical diagnosis or treatment.
